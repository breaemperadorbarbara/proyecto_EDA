Proyecto Dashboard y análisis de datos📊

📚 informe de ventas de libros

  Este proyecto realiza un análisis de los datos de ventas de diferentes librerías sobre diferentes sectores de la sociedad para conocer tendencias y realizar predicciones basadas en los datos de ventas anteriores.
  
  📁 estructura del proyecto
  proyecto_EDA/
  ├── excel con datos y dashboard
  
  ├── csv con datos brutos
  
  ├── readme

  🧮 para este proyecto no ha sido necesaria la instalación de programas ni bibliotecas adicionales.

  Conclusiones en base al análisis de datos:

En el informe general podemos ver los big numbers o KPI's que nos muestran que hemos tenido un total de  ventas de 3150 unidades obteniendo un total de 30.721€ de beneficios totales.

Con el gráfico circular observamos que la mayor parte de las ventas se realiza online (69%), a través del método de pago PayPal.
La categoría que más se vende es la de clásicos, seguida de los thrillers.

En cuanto al tipo de cliente que más compra predominan los hombres y destaca en rango de edad 20-29.

Podemos filtrar con los segmentadores situados a la derecha, para ver las gráficas con datos más específicos.
